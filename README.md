# 🌿 ثبات — تطبيق متابعة هدفك يوم بيوم

**ثبات** تطبيق عربي مجاني، يعمل على الموبايل والكمبيوتر، لمتابعة هدف شخصي مرتبط بالتحكم في العادة السرية أو تقليلها. الفكرة هي المساعدة على بناء عادات واختيارات واعية **من غير لوم أو جلد ذات**.

**التطبيق مكتمل وجاهز للنشر على GitHub Pages بدون تثبيت مكتبات أو إنشاء قاعدة بيانات أو تشغيل خادم خلفي.**


> الصور التالية تستخدم **بيانات تجريبية للتوضيح فقط**. التطبيق الحقيقي يبدأ فارغًا، وبياناتك تفضل على جهازك.

## ✨ المميزات

- **Streak:** عدّاد أيام وساعات ودقائق وثوانٍ منذ بداية السلسلة، مع أفضل سلسلة سابقة.
- **رسالة وتحدي يومي:** تظهر رسالة تشجيعية وفكرة بسيطة تتغير حسب اليوم.
- **زر «ساعدني»:** وقت الرغبة يذكّرك بسبب هدفك، ويعرض تمرين تنفس اختياري مدته 90 ثانية، وبعده اقتراحات عملية متنوعة. تقدر تتجاوز التمرين لو مش مناسب لك.
- **متابعة يومية:** تسجيل المزاج وملاحظة قصيرة، وعرض سجل الأيام على التقويم.
- **يوميات خاصة:** تدوين شدة الرغبة من 1 إلى 5، والمحفزات، وأي ملاحظات.
- **إحصاءات:** أفضل سلسلة، المواقف الصعبة التي تجاوزتها، وملخص المحفزات المتكررة حسب ما سجّلته بنفسك.
- **إنجازات:** معالم من أول 24 ساعة إلى سنة.
- **صندوق أدوات:** خطة «لو حصل كذا، هعمل كذا»، وأفكار لتعديل البيئة المحيطة.
- **بداية جديدة بدون لوم:** تبدأ سلسلة من الصفر، مع الاحتفاظ بأفضل سلسلة واليوميات وسجل البدايات السابقة.
- **نسخ احتياطي:** تصدير واستيراد ملف JSON لحفظ بياناتك أو نقلها لجهاز آخر.
- **واجهة عربية RTL، ووضع فاتح وداكن، وتصميم مناسب للموبايل.**
- **PWA:** يمكن تثبيت التطبيق على الشاشة الرئيسية واستخدامه بدون إنترنت بعد تحميله بنجاح مرة واحدة.

## 🚀 طريقة النشر على GitHub Pages

### 1. ارفع الملفات إلى GitHub

1. فك ضغط الملف `thabat-app.zip` على جهازك.
2. أنشئ مستودعًا **Repository** جديدًا على GitHub، مثلًا: `thabat`.
3. ارفع **محتويات** المجلد `thabat-app` إلى جذر المستودع — وليس ملف ZIP نفسه، ولا تضع الملفات داخل مجلد فرعي إضافي.
4. تأكد من وجود الملفات التالية مباشرة في جذر المستودع: `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`، بالإضافة إلى مجلد `icons` ومجلد `.github`.

يمكنك رفع الملفات من واجهة GitHub باستخدام **Add file → Upload files**. لو واجهتك مشكلة في رفع المجلد المخفي `.github`، استخدم Git من سطر الأوامر بالطريقة الآتية.

### 2. رفع الملفات باستخدام Git (بديل موثوق)

بعد فك الضغط، افتح Terminal في مجلد `thabat-app` ونفّذ:

```bash
git init
git add .
git commit -m "Publish Thabat app"
git branch -M main
git remote add origin https://github.com/USERNAME/thabat.git
git push -u origin main
```

بدّل `USERNAME` باسم حسابك على GitHub، و`thabat` باسم المستودع لو اخترت اسمًا مختلفًا. استخدم مستودعًا فارغًا عند اتباع الخطوات السابقة.

### 3. شغّل GitHub Pages

1. افتح المستودع على GitHub.
2. ادخل إلى **Settings → Pages**.
3. تحت **Build and deployment** اختار **Source: GitHub Actions**.
4. ملف `.github/workflows/deploy.yml` سيشغّل النشر تلقائيًا عند كل `push` لفرع `main`.
5. راجع تبويب **Actions** لتأكيد نجاح النشر.

الرابط غالبًا سيكون:

```
https://USERNAME.github.io/thabat/
```

إذا استخدمت اسمًا مختلفًا للمستودع، غيّر جزء `thabat` في الرابط. لا تحتاج لتعديل الروابط داخل التطبيق؛ فهي نسبية وتدعم GitHub Pages في مجلد المستودع.

**بديل:** يمكنك أيضًا اختيار **Deploy from a branch → main → /(root)** بدل GitHub Actions؛ ملفات الموقع ثابتة وتعمل بهذا الأسلوب كذلك.

## 💻 تشغيل التطبيق على جهازك للتجربة

افتح Terminal داخل المجلد وشغّل:

```bash
python3 -m http.server 5500
```

ثم افتح `http://localhost:5500` في المتصفح. على Windows يمكن تجربة `py -m http.server 5500` إذا لم يعمل الأمر الأول.

قد يفتح `index.html` مباشرة من الملفات، لكن **التثبيت والعمل بدون إنترنت** يحتاجان HTTPS أو `localhost`؛ لهذا الأفضل تشغيل خادم محلي صغير أو استخدام GitHub Pages.

## 📱 تثبيته كتطبيق

- **Android:** افتح رابط GitHub Pages في Chrome، ومن القائمة اختار **Install app** أو **Add to Home screen** عندما تظهر.
- **iPhone / iPad:** افتح الموقع في Safari، ثم **Share → Add to Home Screen**.
- **كمبيوتر:** المتصفحات المدعومة مثل Chrome/Edge قد تعرض خيار التثبيت في شريط العنوان أو القائمة.

ميزة التثبيت تعتمد على دعم المتصفح والجهاز، وقد لا تظهر في كل الحالات.

## 🔔 بخصوص التذكيرات

يوجد تذكير اختياري داخل الإعدادات، لكنه **لا يرسل إشعارات خلفية عندما يكون التطبيق مغلقًا**؛ الإشعار يعمل فقط عندما يكون التطبيق مفتوحًا والمتصفح سمح بالإشعارات. إرسال إشعارات حقيقية خارج التطبيق يحتاج خدمة Push وخادمًا خلفيًا غير موجودين في هذه النسخة الثابتة على GitHub Pages.

الرسالة اليومية والتحدي الجديد يظهران تلقائيًا عندما تفتح التطبيق في يوم جديد.

## 🔒 الخصوصية وحفظ البيانات

- لا توجد حسابات، ولا قاعدة بيانات، ولا متتبعات، ولا Analytics، ولا إرسال للبيانات إلى خادم التطبيق.
- المعلومات المدخلة (مثل السبب الشخصي والملاحظات والمحفزات) تحفظ في **`localStorage` داخل المتصفح على نفس الجهاز والنطاق**.
- مسح بيانات المتصفح أو تغيير الجهاز أو فتح رابط مختلف قد يؤدي لظهور رحلة فارغة؛ استعمل **الإعدادات → صدّر نسخة** بانتظام، ثم **استرجع نسخة** عند الحاجة.
- **ملف النسخة الاحتياطية قد يحتوي على ملاحظات شخصية حساسة**؛ احتفظ به في مكان خاص ولا ترفعه إلى مستودع GitHub عام.
- إذا استضفت تطبيقات أخرى على **نفس النطاق والأصل (origin)**، فالتخزين المحلي مشترك بين صفحات هذا الأصل. للخصوصية الإضافية، استخدم نطاقًا مخصصًا للتطبيق وحده.
- وضع PWA أو التخزين المحلي لا يمثلان تشفيرًا للبيانات؛ احمِ الوصول إلى جهازك.

## ✏️ التخصيص

- غيّر **اسم التطبيق وألوانه** من `index.html` و`styles.css` و`manifest.webmanifest`.
- غيّر **رسائل التشجيع اليومية** من مصفوفة `dailyMessages` في `app.js`.
- غيّر **تحديات اليوم** من `challenges`، واقتراحات وقت الرغبة من `tips`.
- غيّر **معالم الإنجازات** من `milestones`، أو أضف عناصر جديدة.
- بعد تعديل الملفات، ادفع التغييرات إلى GitHub (`git push`) لإعادة النشر.

## 💚 تنبيه صحي

العادة السرية في حد ذاتها **ليست مرضًا** ولا تستلزم الامتناع عنها طبيًا في العموم. اختيار التوقف هدف شخصي مشروع. التطبيق لا يشخّص الإدمان ولا يحل محل العلاج النفسي. إذا شعرت بأن السلوك خارج عن السيطرة بشكل متكرر ويؤثر على نومك أو دراستك أو عملك أو علاقاتك، قد تفيدك مساعدة مختص في الصحة النفسية.
